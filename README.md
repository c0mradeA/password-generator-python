# Custom Password Generator

A minimal Python command-line utility that generates secure, random passwords consisting entirely of alphabetic characters (uppercase and lowercase) and special characters. 

## Features
- Generates passwords with a customizable length.
- Completely excludes numeric digits.
- Guarantees inclusion of at least one lowercase letter, one uppercase letter, and one special character.

## Prerequisites
- Python 3.x installed on your system.
